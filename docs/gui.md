# クエストGUI

F10、`/dailyquest`、`OpenQuests()` exportでクエストボードを開き、Escまたは右上の×で閉じます。
期間切替、進捗・受取状態、リロール残数、全クリア報酬、日次更新までの残り時間を表示します。
抽選設定はボード内の専用画面で変更します。除外する種類にチェックを入れ、抽選対象と反映タイミングを確認して保存します。
初回は設定画面から開始し、保存するまで抽選を行いません。リロール確認にはox_libのダイアログを使います。追加のビルドや外部CDNは不要です。

ネイビーの背景に、一般はブルー、犯罪はコーラル、職業・所属必須はラベンダーの色とアイコンで区別します。
達成状態はミント、報酬はゴールドで表示し、状態・種類は文字でも確認できます。アイコンはCSS内のSVGで、外部フォント・CDNへの通信はありません。
期限と全クリア報酬はカードの上に表示します。説明文は16px以上とし、報酬額と進捗を強調しています。
通信中は「受取中…」「更新中…」「保存中…」と処理内容を表示し、確認待ちの通常報酬・全クリア報酬には
管理者への問い合わせ案内を表示します。

一覧の更新後も操作中の項目にキーボードフォーカスを戻します。受取ボタンがなくなった場合は
同じカードの見出しに移り、通信中に別のタブや閉じるボタンへ移動した場合はその操作位置を保ちます。

画面からは操作名・クエストID・表示期間と、設定保存時の除外指定を送ります。クライアントは直前の一覧応答を参照し、
報酬と抽選の最終検証はサーバーで行います。通信中も閉じる操作は可能で、閉じた後やキャラクター切替後の応答では再表示しません。

## 管理者向けデバッグ

現在のジョブ名が `admin`（出勤状態は不問）、または `Config.DebugAce`（初期値 `admin`）のACEが許可されている場合に、左側に「デバッグ」が表示されます。
ACE名はサーバーの権限設定に合わせて `Config.DebugAce` で変更できます。
サーバーでも一覧取得・設定変更・リセットのたびにこの条件と操作するキャラクターを確認します。
Adminジョブから別のジョブに切り替えても、指定ACEの許可があれば利用を継続できます。

「計測を開始」で未抽選・抽選OFFを含む全40件を検証し、実際の行動後に「一覧を更新」で
未検出／進捗あり／達成、数値、最終検出時刻を確認します。未検出は不具合の判定ではありません。
「検証状態」で絞り込めます。「進捗あり」は達成済みを除き、一覧更新・リセット後も選択を維持します。
画面を閉じても計測を続け、停止ボタン・切断・権限取消で停止します。再接続後は計測を再開してください。
結果は自分のキャラクター別に保存し、個別または全件をリセットできます。検証結果から報酬は発生せず、通常の進捗・報酬は通常どおりです。
参加日数は計測中の異なる日（JST 05:00区切り）に加算します。検証用進捗は日次・週次更新では消さず、リセットまで保持します。

抽選ON/OFFはサーバー共通で保存し、次回抽選・リロールから適用します。提示済みのクエストは継続します。
候補が足りない場合は抽選が成立しないため、日次の短時間枠を含めて十分な候補を残してください。

## ローカル検証

```bash
lua tests/client_spec.lua
node --check ui/quests.js
node tests/countdown_spec.js
```

PlaywrightとChromiumがある環境では `node tests/gui_browser_spec.js` で実際のHTMLを検証できます。
Chromiumのパスは `CHROMIUM_PATH` で指定でき、初期値は `/usr/bin/chromium` です。
サンプルデータとNUIの模擬応答はこのテスト内に閉じています。テスト用HTTPサーバーは終了時に閉じます。
初回導線、通信受付後も続く処理表示、重複操作の抑止、フォーカス復元、閉じた画面への遅延応答、
1280×720での期限・全クリア報酬の表示と375px以上の横幅での収まりを検証します。
埋め込みフレームの背景画素も検査し、起動時・カウントダウンのみの表示・閉じた後・再読み込み後の透過を確認します。
ページ全体への color-scheme: dark はNUIの下地を不透明にするため、指定はクエストパネル内に限定します。

## FiveM実機確認

- F10・コマンドでの表示、マウス・キーボード操作、Escでの入力返却。
- 初回設定、リロールの確定と取消、通常報酬と全クリア報酬の受取。
- 日次更新時の再表示、通信中の閉じる操作、キャラクター切替・リソース停止時の終了。
- 他リソースのNUIと同時に開く運用でのフォーカス、狭い画面でのスクロール。
